# Security Policy

## Reporting a Vulnerability

Please **do not** report security vulnerabilities through public GitHub issues.

Email **security@rolliq.com** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact (data exposure, privilege escalation, etc.)

We will acknowledge receipt within 48 hours and aim to resolve critical issues within 14 days.

## Disclosure Policy

- We will not pursue legal action against researchers acting in good faith
- We ask that you allow us reasonable time to remediate before public disclosure
- We will credit you in release notes if you wish
